#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, W;

    cout << "Enter number of items: ";
    cin >> n;

    vector<int> wt(n + 1), val(n + 1);

    cout << "Enter weight and value of each item:\n";
    for (int i = 1; i <= n; i++)
        cin >> wt[i] >> val[i];

    cout << "Enter knapsack capacity: ";
    cin >> W;

    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));

    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            if (wt[i] <= w)
                dp[i][w] = max(dp[i - 1][w],
                               val[i] + dp[i - 1][w - wt[i]]);
            else
                dp[i][w] = dp[i - 1][w];
        }
    }

    cout << "\nMaximum value = " << dp[n][W] << endl;

    cout << "Items selected (item numbers): ";

    int w = W;

    for (int i = n; i >= 1; i--) {
        if (dp[i][w] != dp[i - 1][w]) {
            cout << i << " ";
            w -= wt[i];
        }
    }

    cout << endl;

    return 0;
}

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, W;

    // 1. Read the total number of items
    cout << "Enter number of items: ";
    cin >> n;

    // Use 1-based indexing for convenient mapping with DP rows
    // wt[i]: weight of the i-th item
    // val[i]: value/profit of the i-th item
    vector<int> wt(n + 1), val(n + 1);

    // 2. Read weight and profit/value for each item
    cout << "Enter weight and value of each item:\n";
    for (int i = 1; i <= n; i++)
        cin >> wt[i] >> val[i];

    // 3. Read maximum weight capacity of the knapsack
    cout << "Enter knapsack capacity: ";
    cin >> W;

    // 4. Initialize 2D DP Table: dp[i][w]
    // Dimensions: (n + 1) rows x (W + 1) columns, initialized to 0
    // State definition: dp[i][w] stores the maximum value attainable 
    // using a subset of the first 'i' items with a total capacity limit of 'w'.
    // Base cases: dp[0][w] = 0 (0 items) and dp[i][0] = 0 (0 capacity) are handled by zero-initialization.
    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));

    // 5. Build DP Table bottom-up (Tabulation)
    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            // Case 1: The current item's weight fits inside capacity 'w'
            if (wt[i] <= w) {
                // Choice A: Exclude item i -> profit remains dp[i - 1][w]
                // Choice B: Include item i -> profit is val[i] + optimal profit of remaining capacity dp[i - 1][w - wt[i]]
                dp[i][w] = max(dp[i - 1][w],
                               val[i] + dp[i - 1][w - wt[i]]);
            }
            // Case 2: The current item is heavier than capacity 'w' -> Cannot include it
            else {
                dp[i][w] = dp[i - 1][w];
            }
        }
    }

    // 6. Optimal result is at dp[n][W] (considering all n items with full capacity W)
    cout << "\nMaximum value = " << dp[n][W] << endl;

    // 7. Backtracking Step: Reconstruct which items were included in the optimal set
    cout << "Items selected (item numbers): ";

    int w = W; // Start with the total capacity

    // Trace backwards from item n down to item 1
    for (int i = n; i >= 1; i--) {
        // If dp[i][w] differs from dp[i - 1][w], item i was included
        if (dp[i][w] != dp[i - 1][w]) {
            cout << i << " "; // Print 1-based item index
            w -= wt[i];       // Reduce remaining capacity by the item's weight
        }
        // Else, dp[i][w] == dp[i - 1][w] means item i was skipped
    }

    cout << endl;

    return 0;
}

# Practical: 0/1 Knapsack Problem Using Dynamic Programming

## 1. Aim

To write a C++ program to solve the 0/1 Knapsack Problem using Dynamic Programming and maximize the total value of selected items without exceeding the given knapsack capacity.

## 2. Theory

### What is the 0/1 Knapsack Problem?

The 0/1 Knapsack Problem is an optimization problem in which a set of items is given, and each item has:

1. Weight: The amount of capacity occupied by an item.
2. Value: The profit or benefit obtained by selecting an item.
3. Knapsack Capacity: The maximum weight that the knapsack can hold.

The objective is to select items such that the total value is maximized without exceeding the given capacity.

It is called 0/1 Knapsack because each item has only two possibilities:

- 1: Select the complete item.
- 0: Do not select the item.

Important: Items cannot be divided into fractions.

### 3. Dynamic Programming

Dynamic Programming is an algorithmic technique that solves a complex problem by breaking it into smaller overlapping subproblems and storing their results to avoid repeated calculations.

The 0/1 Knapsack Problem is commonly solved using Dynamic Programming because each item can either be selected or rejected.

Main idea:

For every item, we have two choices:

1. Include the item if its weight does not exceed the remaining capacity.
2. Exclude the item and retain the previous maximum value.

The maximum value is selected from these two choices.

### 4. Mathematical Formula

Let:

- n = Number of items.
- W = Maximum knapsack capacity.
- \\(wt[i]\\) = Weight of the ith item.
- \\(val[i]\\) = Value of the ith item.
- \\(dp[i][w]\\) = Maximum value obtained using the first i items with capacity w.

Recurrence Relation:

If the weight of the current item is less than or equal to the available capacity:

\\[ dp[i][w]=\max \begin{cases} dp[i-1][w]\\\ val[i]+dp[i-1][w-wt[i]] \end{cases} \\]

Otherwise:

\\[ dp[i][w]=dp[i-1][w] \\]

Base Conditions:

\\[ dp[0][w]=0 \\]

\\[ dp[i][0]=0 \\]

This means:

- If there are no items, maximum value is zero.
- If capacity is zero, maximum value is zero.

## 5. Working of the Algorithm

The algorithm follows these steps:

1. Start the program.
2. Read the number of items.
3. Read the weight and value of each item.
4. Read the knapsack capacity.
5. Create a two-dimensional DP table initialized with zeros.
6. Traverse each item and every possible capacity.
7. Check whether the current item can fit into the available capacity.
8. If it fits, calculate both inclusion and exclusion values.
9. Store the maximum of these two values in the DP table.
10. If it does not fit, copy the previous value.
11. After filling the table, display the maximum value.
12. Backtrack through the DP table to identify selected items.
13. Stop the program.

## 7. Explanation of Important Code Statements

### A. Taking Input

```
int n, W;

cin >> n;

vector<int> wt(n + 1), val(n + 1);
```

- `n` stores the number of items.
- `W` stores the knapsack capacity.
- `wt` stores the weights of items.
- `val` stores the values of items.

Vectors are created with size n+1 because indexing starts from 1 in this program.

### B. Creating DP Table

```
vector<vector<int>> dp(n + 1,
    vector<int>(W + 1, 0));
```

Creates a two-dimensional DP table with n+1 rows and W+1 columns.

Every cell is initially initialized to zero.

### C. Checking Item Weight

```
if (wt[i] <= w)
```

Checks whether the current item's weight is less than or equal to the available capacity.

### D. Including or Excluding an Item

```
dp[i][w] = max(dp[i - 1][w],
    val[i] + dp[i - 1][w - wt[i]]);
```

This statement calculates two possibilities:

- `dp[i-1][w]`: Excludes the current item.
- `val[i] + dp[i-1][w-wt[i]]`: Includes the current item.

The `max()` function selects the option that gives maximum value.

### E. Excluding an Item

```
else
    dp[i][w] = dp[i - 1][w];
```

If the item's weight exceeds the available capacity, the item cannot be selected.

Therefore, the previous maximum value is copied.

### F. Finding Selected Items (Backtracking)

```
int w = W;

for (int i = n; i >= 1; i--) {
    if (dp[i][w] != dp[i - 1][w]) {
        cout << i << " ";
        w -= wt[i];
    }
}
```

This loop traverses the DP table backwards to identify selected items.

- If the current DP value differs from the previous row, the current item was selected.
- Its item number is displayed.
- Its weight is subtracted from the remaining capacity.

Why do we traverse backwards?

Because the DP table is constructed using previous rows, so we can trace the decisions from the final answer back to the first item.

Greedy makes locally optimal choices at each step, whereas Dynamic Programming considers subproblems and stores their results to obtain an optimal solution.

14\. Why is Greedy not always optimal for 0/1 Knapsack?

Because selecting the item with the highest profit-to-weight ratio first may prevent a better combination of complete items.

15\. What is an overlapping subproblem?

A subproblem that is solved repeatedly during the execution of an algorithm.

16\. What is optimal substructure?

A problem has optimal substructure when its optimal solution can be constructed using optimal solutions of smaller subproblems.

20\. What happens when the capacity is zero?

No items can be selected, so the maximum value is zero.

## 3. Why Are Different Algorithms Used?

Fractional Knapsack – Greedy Algorithm

- Select the item with the highest profit-to-weight ratio.
- Take the complete item if possible.
- Otherwise, take the required fraction.
- This approach always gives an optimal solution for fractional knapsack.

0/1 Knapsack – Dynamic Programming

- Each item has only two choices: select (1) or reject (0).
- We consider different combinations of items.
- Dynamic Programming stores previously calculated results to avoid repeated calculations.
- Greedy selection based only on profit-to-weight ratio may give a suboptimal answer.
