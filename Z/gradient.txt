# Gradient Descent Algorithm – Theory

## 1. Aim

To implement the Gradient Descent algorithm to find the local minimum of a function \\(y=(x+3)^2\\), starting from \\(x=2\\).

## 2. Theory

Gradient Descent is an optimization algorithm used to find the minimum value of a function by repeatedly updating the current value in the direction opposite to its gradient (derivative).

It is commonly used in Machine Learning to minimize loss or cost functions.

### Given function

\\[ y=(x+3)^2 \\]

Differentiate with respect to \\(x\\):

\\[ \frac{dy}{dx}=2(x+3) \\]

The derivative represents the slope of the function.

At the minimum point:

\\[ \frac{dy}{dx}=0 \\]

\\[ 2(x+3)=0 \\]

\\[ \boxed{x=-3} \\]

Therefore, the minimum value of the function is:

\\[ y=(-3+3)^2=\boxed{0} \\]

## 3. Working of Gradient Descent

The algorithm updates the current value using the formula:

\\[ \boxed{x\_{new}=x\_{old}-\alpha f'(x)} \\]

Where:

- \\(x\_{new}\\): Updated value of x.
- \\(x\_{old}\\): Previous value of x.
- \\(\alpha\\): Learning rate.
- \\(f'(x)\\): Derivative or gradient of the function.

| -------------------- | -------- | ------------------ |
| `cur_x`              | 2        | Initial value of x |
| `rate`               | 0.01     | Learning rate      |
| `precision`          | 0.000001 | Stopping tolerance |
| `previous_step_size` | 1        | Initial step size  |
| `max_iters`          | 1000     | Maximum iterations |
| `iters`              | 0        | Iteration counter  |

## 6. Advantages

1. Simple and easy-to-implement optimization algorithm.
2. Requires less memory for storing intermediate values.
3. Useful for minimizing complex loss functions in machine learning.
4. Can handle functions with many input variables.
5. Iteratively improves the solution towards the minimum.

## 7. Disadvantages

1. Performance depends heavily on the selected learning rate.
2. May converge slowly when the learning rate is very small.
3. Large learning rates may cause overshooting or divergence.
4. Can get stuck at local minima in non-convex functions.
5. Requires a differentiable objective function for standard gradient-based updates.
