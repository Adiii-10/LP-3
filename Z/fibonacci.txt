    if (n <= 1) return n;

    long long a = 0, b = 1, c;

    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }

    return b;
}

#include <iostream>

// ==========================================
// 1. Iterative Approach: O(n) time, O(1) space
// ==========================================
long long fibIter(int n) {
    // Base cases: F(0) = 0, F(1) = 1
    if (n <= 1) return n;

    // Track the two preceding numbers:
    // 'a' stores F(i - 2), initialized to F(0) = 0
    // 'b' stores F(i - 1), initialized to F(1) = 1
    // 'c' holds the newly computed Fibonacci number F(i)
    long long a = 0, b = 1, c;

    // Iteratively build the series from index 2 up to n
    for (int i = 2; i <= n; i++) {
        c = a + b; // F(i) = F(i - 1) + F(i - 2)
        a = b;     // Slide window forward: shift F(i - 1) into 'a'
        b = c;     // Shift newly computed F(i) into 'b'
    }

    // 'b' holds the n-th Fibonacci number upon loop completion
    return b;
}

// ==========================================
// 2. Recursive Approach: O(2^n) time, O(n) call-stack space
// ==========================================
long long fibRec(int n) {
    // Base cases: Stop recursion when n reaches 0 or 1
    if (n <= 1) return n;

    // Recurrence relation: compute preceding terms via recursive branches
    // Note: Recalculates overlapping subproblems repeatedly
    return fibRec(n - 1) + fibRec(n - 2);
}

int main() {
    int n;

    // Prompt user for number of terms to print
    cout << "Enter n: ";

    // Input validation: Fibonacci sequence indices cannot be negative
    if (n < 0) {
        cout << "Please enter a non-negative number.";
        return 0; // Terminate execution early on invalid input
    }

    for (int i = 0; i < n; i++)

    // Warning: Becomes very slow when n exceeds ~40 due to exponential time complexity
    cout << "\nFibonacci series (recursive): ";
    for (int i = 0; i < n; i++)
        cout << fibRec(i) << " ";

    return 0;

# Practical: Implementation of Fibonacci Series using Iterative and Recursive Methods

## 1. Aim

To write a C++ program to generate the Fibonacci series using iterative and recursive approaches and compare their performance in terms of time and space complexity.

## 2. Theory

### What is the Fibonacci Series?

The Fibonacci series is a sequence of numbers in which each number is obtained by adding the previous two numbers.

- The first Fibonacci number is 0.
- The second Fibonacci number is 1.
- Every subsequent number is the sum of the previous two numbers.

Mathematical recurrence relation:

\\[ F(n)=F(n-1)+F(n-2) \\]

Where:

- \\(F(0)=0\\) — First base condition.
- \\(F(1)=1\\) — Second base condition.
- \\(F(n)\\) — Fibonacci number at position n.

Example:

If n = 7, the Fibonacci series is:

# 0, 1, 1, 2, 3, 5, 8

First 7 Fibonacci numbers

## 3. Approaches Used

There are two approaches implemented in this program:

### A. Iterative Approach

The iterative approach generates Fibonacci numbers using loops instead of function calls.

Working:

1. Initialize three variables: `a = 0`, `b = 1` and `c`.
2. Check whether n is 0 or 1 and return n directly.
3. Use a for loop starting from 2 up to n.
4. Calculate the next Fibonacci number using `c = a + b`.
5. Update a with b and b with c.
6. Return b as the required Fibonacci number.

Example:

For n = 5:

| Iteration | a | b | c = a + b |
| --------- | - | - | --------- |
| Initial   | 0 | 1 | —         |
| 2         | 1 | 1 | 1         |
| 3         | 1 | 2 | 2         |
| 4         | 2 | 3 | 3         |
| 5         | 3 | 5 | 5         |

Therefore, the fifth index Fibonacci number is 5.

### B. Recursive Approach

The recursive approach generates Fibonacci numbers by calling the same function repeatedly with smaller input values.

Working:

1. Define a function `fibRec(int n)`.
2. Check the base condition: if n is less than or equal to 1, return n.
3. Otherwise, call the same function with n-1 and n-2.
4. Add both returned values.
5. Continue until the base condition is reached.
6. Return the calculated Fibonacci number.

Recursive formula:

\\[ F(n)=F(n-1)+F(n-2) \\]

Example:

For n = 4:

\\[ F(4)=F(3)+F(2) \\]

\\[ =(F(2)+F(1))+(F(1)+F(0)) \\]

\\[ =(1+1)+(1+0)=3 \\]

Therefore, F(4) = 3.

## 4. Difference Between Iterative and Recursive Approaches

| Iterative                      | Recursive                               |
| ------------------------------ | --------------------------------------- |
| Uses loops.                    | Uses function calls.                    |
| Does not use recursion.        | Uses recursion.                         |
| Requires less memory.          | Requires more memory due to call stack. |
| Faster for large inputs.       | Slower for large inputs.                |
| Avoids function call overhead. | Has function call overhead.             |
| Time complexity is O(n).       | Time complexity is O(2ⁿ).               |

## 5. Time and Space Complexity Analysis

Complexity analysis determines the amount of time and memory required by an algorithm as the input size increases.

### Iterative Approach

- Time Complexity: O(n) – The loop executes n-1 times for calculating one Fibonacci number.
- Space Complexity: O(1) – Only three variables are used, regardless of input size.

### Recursive Approach

- Time Complexity: O(2ⁿ) – Repeated function calls calculate the same Fibonacci values multiple times.
- Space Complexity: O(n) – Recursive calls are stored in the function call stack, with maximum recursion depth proportional to n.

### Complexity Comparison

| Parameter    | Iterative | Recursive   |
| ------------ | --------- | ----------- |
| Best time    | O(1)      | O(1)        |
| Average time | O(n)      | Exponential |
| Worst time   | O(n)      | O(2ⁿ)       |
| Space        | O(1)      | O(n)        |

Note: The above complexities describe calculating a single Fibonacci number. Your program prints n numbers, so the total complexity differs:

- Iterative series generation: O(n²), because `fibIter()` is called separately for each index.
- Recursive series generation: O(2ⁿ), as the exponential costs are dominated by the last Fibonacci calculation.

## 7. Advantages

### Iterative Approach

1. Requires less memory because it uses a fixed number of variables.
2. Executes faster because it avoids repeated function calls.
3. Efficient for generating large Fibonacci sequences.
4. Does not cause stack overflow due to deep recursion.
5. Easy to optimize for better performance.

### Recursive Approach

1. Code is short, simple and easy to understand.
2. Directly follows the mathematical definition of Fibonacci series.
3. Demonstrates the concept of recursion effectively.
4. Useful for understanding function calls and base conditions.
5. Can be optimized using memoization or dynamic programming.

## 8. Disadvantages

### Iterative Approach

1. Requires explicit loop implementation and variable updates.
2. May be less intuitive for understanding recursive mathematical relationships.
3. The logic becomes comparatively lengthy for certain recursive problems.
4. Requires manual management of previous Fibonacci values.

### Recursive Approach

1. Recalculates the same Fibonacci values multiple times.
2. Requires additional memory for maintaining the function call stack.
3. Becomes very slow for large input values.
4. May cause stack overflow due to excessive recursive calls.
5. Has higher function call overhead compared to iteration.
