import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv('sales_data_sample.csv', encoding='latin1')
X = df.select_dtypes(include='number').drop(
    columns=['ORDERNUMBER', 'ORDERLINENUMBER', 'QTR_ID',
             'MONTH_ID', 'YEAR_ID', 'POSTALCODE'], errors='ignore'
)
scaler = StandardScaler()
X = scaler.fit_transform(X)

inertia = []
for k in range(1, 11):
    model = KMeans(n_clusters=k, random_state=42, n_init=10)
    model.fit(X)
    inertia.append(model.inertia_)

plt.plot(range(1, 11), inertia, marker='o')
plt.xlabel('Number of clusters')
plt.ylabel('Inertia')
plt.title('Elbow Method')
plt.show()

kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
df['Cluster'] = kmeans.fit_predict(X)


print(df['Cluster'].value_counts())

# ==============================================================================
# SECTION 1: LIBRARY IMPORTS
# ==============================================================================

# pandas: Used for tabular data manipulation and reading CSV files into DataFrames.
import pandas as pd

# matplotlib.pyplot: Used for creating 2D visualizations, such as the Elbow Method curve.
import matplotlib.pyplot as plt

# StandardScaler: Performs z-score standardization (mean = 0, variance = 1).
# Crucial for distance-based clustering algorithms like K-Means.
from sklearn.preprocessing import StandardScaler

# KMeans: Scikit-learn implementation of the K-Means clustering algorithm.
from sklearn.cluster import KMeans


# ==============================================================================
# SECTION 2: DATA LOADING & PREPROCESSING
# ==============================================================================

# Load the sales dataset.
# encoding='latin1' (ISO-8859-1) avoids UnicodeDecodeError often triggered by special characters in retail data.
df = pd.read_csv('sales_data_sample.csv', encoding='latin1')

# 1. select_dtypes(include='number'): Retains only numerical columns since K-Means relies on mathematical distances.
# 2. drop(...): Strips identifiers, sequential order counters, temporal categoricals, and zip codes.
#    These columns either lack continuous numerical meaning or introduce misleading distance biases.
# errors='ignore' prevents crashes if any listed column name is missing from the file.
X = df.select_dtypes(include='number').drop(
    columns=['ORDERNUMBER', 'ORDERLINENUMBER', 'QTR_ID',
             'MONTH_ID', 'YEAR_ID', 'POSTALCODE'], errors='ignore'
)

# K-Means calculates Euclidean distance (d = sqrt(sum((x_i - y_i)^2))).
# Features with large scales (e.g., 'SALES' in thousands) would dominate features with small scales (e.g., 'QUANTITYORDERED' in tens).
# StandardScaler gives every feature equal geometric weight.
scaler = StandardScaler()
X = scaler.fit_transform(X)


# ==============================================================================
# SECTION 3: DETERMINING OPTIMAL 'K' (THE ELBOW METHOD)
# ==============================================================================

# Inertia: Sum of squared distances of samples to their closest cluster center (WCSS - Within-Cluster Sum of Squares).
inertia = []

# Evaluate K-Means for cluster counts from k = 1 up to k = 10
for k in range(1, 11):
    # n_clusters=k: Number of centroids to generate.
    # random_state=42: Ensures reproducible centroid initialization.
    # n_init=10: Runs the algorithm 10 times with distinct initial centroids and keeps the best outcome (lowest inertia).
    model = KMeans(n_clusters=k, random_state=42, n_init=10)
    model.fit(X)
    inertia.append(model.inertia_)

# Plot the Elbow Curve: Number of clusters vs. Inertia
plt.plot(range(1, 11), inertia, marker='o')
plt.xlabel('Number of clusters')
plt.ylabel('Inertia')
plt.title('Elbow Method')
plt.show()  # The "elbow" point (where inertia drop levels off) suggests the most natural K


# ==============================================================================
# SECTION 4: FINAL MODEL TRAINING & CLUSTER ASSIGNMENT
# ==============================================================================

# Fit the chosen model (here configured with k=3 based on elbow observation)
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)

# fit_predict(): Computes cluster centers and assigns each row to its nearest centroid index (0, 1, or 2).
# Append the cluster labels directly back to the original DataFrame for customer/order segmentation analysis.
df['Cluster'] = kmeans.fit_predict(X)

# Display the count of records grouped under each cluster label
print('Cluster Counts:')
print(df['Cluster'].value_counts())

### 2.5 What is K-Means Clustering?

K-Means is an unsupervised machine learning algorithm used to divide data points into K different clusters based on their similarities.

It groups data points by minimizing the distance between each data point and the centroid of its assigned cluster.

A centroid represents the center of a cluster.

Working of K-Means:

1. Select the number of clusters K.
2. Initialize K cluster centroids.
3. Calculate the distance between each data point and all centroids.
4. Assign each data point to its nearest centroid.
5. Recalculate the centroids using the mean of the assigned data points.
6. Repeat the assignment and centroid calculation steps.
7. Stop when the centroids no longer change significantly or the algorithm reaches its stopping condition.

### 2.6 K-Means Objective Function

The main objective of K-Means is to minimize the sum of squared distances between data points and their assigned cluster centroids.

This is known as Within-Cluster Sum of Squares (WCSS), also called inertia in Scikit-learn.

\\[ WCSS=\sum\_{i=1}^{K}\sum\_{x\in C_i} ||x-\mu_i||^2 \\]

Where:

- \\(K\\) = Number of clusters.
- \\(C_i\\) = Set of data points in cluster i.
- \\(x\\) = Individual data point.
- \\(\mu_i\\) = Centroid of cluster i.

Lower inertia indicates that data points are closer to their respective cluster centroids.

### 4.3 Feature Scaling using StandardScaler

Feature scaling is the process of bringing numerical features to a similar scale.

It is important in K-Means because the algorithm calculates distances between data points and centroids.

Formula:

\\[ Z=\frac{X-\mu}{\sigma} \\]

Where:

- \\(X\\) = Original feature value.
- \\(\mu\\) = Mean of the feature.
- \\(\sigma\\) = Standard deviation.
- \\(Z\\) = Standardized value.

Advantages of scaling:

1. Prevents large-valued features from dominating distance calculations.
2. Gives all features comparable importance in distance measurement.
3. Improves clustering performance.
4. Helps K-Means identify meaningful groups.

### 4.4 What is Inertia?

Inertia is the sum of squared distances between each data point and its assigned cluster centroid.

It measures how compact the clusters are.

- Lower inertia indicates more compact clusters.
- Higher inertia indicates greater distances from points to centroids.
- Inertia generally decreases when the number of clusters increases.

In this practical, inertia is calculated for different values of K using:

```
model.inertia_
```

### 4.5 What is the Elbow Method?

The Elbow Method is a technique used to determine the optimal number of clusters in K-Means.

It involves running K-Means with different values of K and calculating the inertia for each value.

The inertia values are plotted against the number of clusters.

The point where the reduction in inertia starts slowing down significantly is called the Elbow Point.

This point is considered a suitable number of clusters.

Steps of Elbow Method:

1. Start with K = 1.
2. Apply K-Means for different values of K.
3. Calculate inertia for each clustering result.
4. Plot K values on the X-axis.
5. Plot inertia values on the Y-axis.
6. Identify the elbow point where the decrease in inertia becomes slower.
7. Select the corresponding K value.

In this practical: The program checks K values from 1 to 10 and plots their inertia values to identify a suitable number of clusters.
